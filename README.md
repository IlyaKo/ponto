Браузерный редактор схем для вязания на спицах.

* Рисование узоров на адаптивной сетке с поддержкой японских петельных символов (JIS).
* Экспорт схем (JSON / изображение) и автосохранение в браузере.

Работает полностью на клиенте, не требует регистрации и установки.
